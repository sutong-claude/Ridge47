# Ridge 47

Hourly-built tactical 3D FPS in the browser. Original dusk quarry + night hangar. Not affiliated with any commercial shooter.

Open `index.html` (module + Three.js CDN) or serve the folder. Click to pointer-lock.

Controls: WASD, mouse look, Shift sprint, Ctrl crouch, Space jump, 1/2/3 weapons, I inspect, RMB ADS, G grenade, R reload, F extract (20s near amber crate when few hostiles remain). [ ] sensitivity, -/= FOV.

See GAME.md for the hourly contract and backlog.
